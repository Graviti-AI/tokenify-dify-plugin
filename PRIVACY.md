# Privacy

This plugin sends the prompts, model parameters and API key you configure in Dify to Tokenify's API at `https://api.tokenify.dev/v1`, and returns the model's response to Dify. It sends data to no other host.

The plugin itself stores nothing: it keeps no logs, files or copies of your prompts, responses or credentials. Your API key is stored by Dify as an encrypted credential, like any other model provider key.

How Tokenify handles the requests it receives is described in its privacy policy: https://www.tokenify.dev/privacy/

Questions: support@tokenify.dev
